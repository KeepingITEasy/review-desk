# Review Desk

A single-page tool for posting your own honest review of a business to several review sites.

Write the review once, adjust it per site if needed, then copy the text and open each site's search for the business to post it yourself from your own account.

Sites: Google, Yelp, Facebook, Nextdoor, plus optional BBB, Trustpilot, Tripadvisor and Bing Places.

## Use

Open `index.html` in a browser. Drafts are saved in your browser's local storage.

The page never submits reviews automatically; you paste and submit on each site.
